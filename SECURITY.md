# Security Policy

Do not report vulnerabilities in a public issue. Send a private report through
the [M-Agent private security advisory form](https://github.com/lingdu0007/M-Agent/security/advisories/new).
Include the affected version, reproduction steps without credentials or private
payloads, and an impact assessment.

Do not send API keys, access tokens, provider request/response bodies, customer
data, or private endpoint URLs. Redact them before submitting the report.

Maintainers will acknowledge valid reports privately and publish release
guidance after remediation. This project does not promise a hosted response
service or a particular response-time SLA.
