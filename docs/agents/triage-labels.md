# 分诊状态

工程技能使用五个标准分诊角色。下表将这些角色映射为本仓库 Issue Tracker 使用的实际状态值。

| 标准角色 | 本仓库状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 Issue |
| `needs-info` | `needs-info` | 正在等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由 AFK Agent 直接处理 |
| `ready-for-human` | `ready-for-human` | 需要由人工实现 |
| `wontfix` | `wontfix` | 不会处理该 Issue |

当技能提到某个标准分诊角色时，使用表中对应的本仓库状态值。
